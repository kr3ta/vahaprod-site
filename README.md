# VAHAPROD — сайт медиа-агентства

Адаптивный статический сайт VAHAPROD. Репозиторий содержит HTML-страницу и используемые видеоассеты.

## Состав

- `index.html` — главная страница и стили сайта
- `assets/` — видео для кейсов и блока продакшна

## Локальный просмотр

Откройте `index.html` в браузере. Для корректного воспроизведения видео используйте локальный веб-сервер или разверните папку на статическом хостинге.

## Деплой на Netlify

Разверните корень репозитория (`/`) как статический сайт. Сборка не требуется.

Сайт: https://vahaprod.netlify.app/
