# VAHAPROD — сайт медиа-агентства

Адаптивный статический сайт VAHAPROD. В репозитории лежат HTML-страница и стили проекта.

## Состав

- `index.html` — главная страница и стили сайта
- Изображения, включённые в HTML, остаются в исходнике

Видеоассеты намеренно не загружены в GitHub. Уже опубликованный сайт на Netlify продолжает работать со своей папкой ассетов. Если разворачивать эту копию отдельно, для видео нужно добавить исходные MP4-файлы в папку `assets/`.

## Локальный просмотр

Откройте `index.html` в браузере. Для полного отображения видео используйте папку ассетов из Netlify-бандла рядом с HTML.

## Деплой на Netlify

Разверните корень проекта (`/`) как статический сайт. Сборка не требуется. Для полностью работающей версии дополнительно нужна папка ассетов.

Сайт: https://vahaprod.netlify.app/
